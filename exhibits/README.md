# exhibits/

Study screenshots, diagrams and cut-out PNGs that go up on screen while you talk and point at them.

- **You** put the files here (drag them in, or `./reels exhibits add ~/Downloads/shot.png`). Claude never downloads or generates them.
- They are only ever shown as an overlay on your footage (`"exhibits"` in a plan), never as a shot of their own.
- A screenshot that shows the authors/journal is nicer, but not required.
- A PNG with a transparent background can be shown as a raw cut-out (`"style": "cutout"`).

`./reels exhibits` lists what's here and which plans use it. How to use them: `.claude/skills/cycling-reels/reference/exhibits.md`.
