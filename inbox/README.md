Drop raw ride videos (GoPro, phone, action cam) and photos here.

`./reels ingest` moves each file into library/media/, makes a contact sheet,
and checks for talking. Anything ingested disappears from this folder, so
whatever is left here is new. GoPro MAX / MAX 2 `.360` files go in as they
come off the camera, as do 360 MP4s and 360 photos. GoPro .LRV/.THM sidecars
and Insta360 .insv files are left alone (export Insta360 clips as 360 MP4
first).
